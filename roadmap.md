# RPG Life — Roadmap (текущий функционал)

Краткий обзор того, что уже есть в приложении, по блокам.

---

## Общее

- **Профили** — один активный персонаж: имя, уровень, XP, валюта (монеты, кристаллы). Данные хранятся в браузере (localStorage).
- **Шапка** — имя профиля, уровень, прогресс до следующего уровня, монеты и кристаллы.
- **Тема** — светлая / тёмная / по системе, выбор акцентного цвета (в настройках).
- **Экспорт/импорт** — выгрузка и загрузка всех данных (Настройки).

---

## Задачи

- **Типы задач:** чекбокс (сделал/не сделал), счётчик (прогресс N из M), вложенные (подзадачи).
- **Группы** — папки для задач (создание, переименование, удаление).
- **Сложность** — лёгкая / средняя / сложная / очень сложная; от неё зависят XP и штрафы.
- **Атрибут** — привязка задачи к атрибуту (Сила, Интеллект и т.д.); за выполнение даётся XP атрибуту.
- **Дедлайн** — дата и время (опционально).
- **Повторение** — один раз / ежедневно / еженедельно / ежемесячно / ежегодно / мгновенно (снова доступна после выполнения) / свой интервал.
- **Награда** — монеты за выполнение; штраф (XP/монеты) за пропуск или отказ.
- **Действия:** выполнить, пропустить, бросить; для счётчика — +/-; для вложенных — галочки по подзадачам.
- **Архив** — скрытие задачи без удаления.

---

## Привычки

- **Карточки привычек** — иконка, цвет, название, награды (XP, монеты, гемы).
- **+ / −** — плюс за выполнение, минус за срыв (включение/отключение каждого).
- **Один раз в день** — по умолчанию за день учитывается одно действие (+ или −); экспериментальный режим — несколько кликов как «следующие дни».
- **Привязка к атрибуту** — XP за действие идёт выбранному атрибуту.
- **Множитель сложности** — через N дней награда растёт (лёгкий/средний/тяжёлый или свой множитель).
- **Streak** — серия дней подряд с хотя бы одним «+».
- **Календарь** — просмотр истории по дням (календарное модальное окно).

---

## Магазин

- **Предметы** — название, описание, редкость (обычный → легендарный), стоимость (монеты/кристаллы).
- **Способ получения** — можно купить / можно получить бесплатно; при покупке — списание валюты.
- **Лутбокс** — предмет может быть лутбоксом: при «открытии» случайная награда из таблицы (шансы в %, предметы и валюта).
- **Рецепты крафта** — блок под лутбоксом в форме предмета: пустое состояние, кнопка «Добавить рецепт» → выбор типа (Создание предмета / Материал для крафта / Преобразование — Улучшение); у каждого типа своё окно настроек (пока заглушки).
- **Вкладки** — Магазин (список товаров) и Инвентарь (купленное).
- **Использование** — кнопка «Использовать» или «Открыть» (для лутбокса); предмет тратится, награда начисляется.

---

## Крафт

- **Рецепты** — сбор фрагментов → крафт предмета (фрагменты + результат).
- **Источник фрагментов** — случайный дроп (шанс %) или привязка к конкретным задачам.
- **Прогресс** — сколько фрагментов собрано / сколько нужно; кнопка «Скрафтить» при полном наборе.
- **Редкость результата** — от обычного до легендарного; иконка и название фрагмента и результата.
- **Случайный дроп** — при завершении задач может выпасть фрагмент по рецептам с random_drop.

---

## Статус

- **Профиль** — уровень, XP, прогресс до следующего уровня (кривая: standard / fast / custom).
- **Атрибуты** — список с уровнями и XP; радар-диаграмма по атрибутам.
- **Статистика** — всего задач выполнено, привычек (+/−), монет заработано, предметов скрафчено, текущий и лучший streak, последняя активность.

---

## Достижения

- **Условия разблокировки:** задачи выполнены, привычки (+ N раз), уровень атрибута, streak дней, монет заработано, предметов скрафчено, вручную.
- **Прогресс** — отображение текущего прогресса к цели.
- **Разблокировка** — автоматическая при выполнении условия или вручную; награды (XP, монеты, гемы, предметы) при получении достижения.

---

## Настройки

- **Профиль** — смена имени персонажа; отображение уровня, XP и числа атрибутов.
- **Атрибуты** — добавление, редактирование, удаление; имя, ключ, иконка, цвет.
- **Кривая уровней** — режим (standard / fast / custom); для custom — сегменты «уровни X–Y, N XP за уровень».
- **Тема** — светлая / тёмная / как в системе.
- **Акцент** — цвет интерфейса (синий, фиолетовый, розовый и др.).
- **Уведомления** — вкл/выкл; опции для ежедневных напоминаний и достижений.
- **Язык** — ru / en (задел).
- **Данные** — экспорт JSON, импорт, сброс прогресса.

---

## Что не входит в текущий функционал

- **Квесты** — страница есть в коде, в навигации не используется; функционала нет.
- **Группы предметов в магазине** — в форме предмета есть заглушка «Выберите группу», логики нет.
- **Полная логика рецептов в форме предмета** — три типа рецептов (создание/материал/улучшение) только с окнами-заглушками, без сохранения в store.
