# Как сохранить и удобно работать с проектом RPG Life

## Где лежит код

Весь код уже сохранён в папке:
```
c:\Users\Jahseh\rpg-life
```

Внутри:
- **src/** — исходный код (страницы, компоненты, store)
- **electron/** — код окна приложения
- **public/** — статика (иконки и т.д.)
- **package.json** — зависимости и скрипты

---

## 1. Резервная копия (простой способ)

### Вариант А: Копировать папку
- Скопируйте всю папку `rpg-life` в другое место (например, на флешку или в `Документы`).
- Имя можно сделать с датой: `rpg-life-2025-01-31`.

### Вариант Б: ZIP-архив
- Правый клик по папке `rpg-life` → **Отправить** → **Сжатая ZIP-папка**.
- Архив можно хранить в облаке или на диске.

**Важно:** в архив/копию не обязательно включать папку `node_modules` (она большая и ставится заново командой `npm install`).

---

## 2. Версии и история (если поставите Git)

1. Установите **Git**: https://git-scm.com/download/win  
2. Откройте терминал в папке проекта (`c:\Users\Jahseh\rpg-life`).
3. Выполните:

```bash
git init
git add .
git commit -m "Первый коммит - RPG Life"
```

Дальше можно:
- Делать `git add .` и `git commit -m "описание"` после важных изменений.
- Подключить GitHub/GitLab и отправлять код туда (`git remote add origin ...`, `git push`).

Так вы сохраняете историю изменений и сможете откатиться к любой версии.

---

## 3. Удобная работа в Cursor

- Открывайте папку **File → Open Folder** → `c:\Users\Jahseh\rpg-life`.
- Поиск по проекту: **Ctrl+Shift+F**.
- Переход к файлу: **Ctrl+P** и начало имени файла.
- Терминал внизу: **Ctrl+`** — там запускать `npm run dev`, `npm install` и т.д.

---

## 4. Что запускать

| Действие              | Команда в терминале   |
|-----------------------|------------------------|
| Установить зависимости| `npm install`         |
| Запустить приложение  | `npm run dev`          |
| Собрать для релиза    | `npm run build`        |

После `npm run dev` откройте в браузере адрес, который покажет Vite (например, http://localhost:5176/).

---

## 5. Синхронизация через облако

Можно хранить папку `rpg-life` в папке, которую синхронизирует:
- **OneDrive**
- **Google Drive**
- **Dropbox**

Тогда копия проекта будет автоматически в облаке. Папку `node_modules` лучше добавить в исключения синхронизации (она восстанавливается через `npm install`).
